# Bookmarks

**Track** buttons 1–4 are bookmarks. Shift and a button stores the lane and page on screen, including a page of the aux lane. A short press jumps there, and pressing it again returns to the lane, page, and Journal/Set mode from before. Holding one shows that page until the finger lifts. Delete and a button clears that bookmark. A stored button lights in the same colour as that page’s pad and changes colour when you overwrite it. An empty button stays off. The bookmark you are currently on blinks.
