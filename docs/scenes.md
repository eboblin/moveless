# Journal and sets

**Record** appends a new scene to the Journal. It never overwrites. Each scene gets its own pad color. The newest occupied pad blinks. Empty pads stay off. The Journal and a Set show tracks newest first: the new one sits at the bottom left and shifts the others one pad to the right, then up. The Journal keeps the newest 32 on the first page. **Plus** opens the next older page. **Minus** returns toward the newest.

The **Menu** button (three lines under the jog) switches the pads between Journal and Set. The button is yellow in Journal and purple in Set.

**Copy** puts the newest Journal scene on the clipboard. Hold Copy and press a pad in Set mode to add that scene to the active Set. The Journal scene stays. **Delete** plus a lane step restores that lane’s parameters to the factory defaults. Mute, lock, and the mixer stay. **Delete** plus a scene pad always deletes that pattern: in Set it drops the reference from the active Set; in Journal it removes the scene and every Set link to it. **Delete** plus **Minus** deletes the Set itself. **Plus** and **Minus** move between Sets the same way as journal pages: plus toward the next set, minus toward the previous.
