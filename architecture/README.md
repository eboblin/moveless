# Architecture

Документы в этой папке — источник правды по продукту. Код, который им противоречит, нужно либо поправить, либо сначала обновить документ.

- [initial.md](initial.md) — снимок брейншторма. Не переписывать задним числом. Новые решения сюда не дописывать.
- [deferred.md](deferred.md) — что сознательно не входит в первую версию. Перед тем как добавить жест, параметр или режим, проверить, что его здесь нет.
- [state.md](state.md) — сцена, project, генератор, гармония.
- [morph.md](morph.md) — морф, Wander, Capture.
- [pages.md](pages.md) — страницы и жесты.
- [voices.md](voices.md) — адаптер движков, лицензии, замер.

По ходу разработки рядом появляются файлы актуальной архитектуры: модель состояния, страницы, морф, голоса. Их обновляют в том же изменении, что и код. Пункт из `deferred.md`, который начали делать, переносят в актуальный файл и удаляют отсюда.
