# Состояние

Код: `src/core/types.ts`, `src/core/defaults.ts`, `src/core/phrase.ts`, `src/core/persist.ts`.

Числа в сцене нормализованы. Подписи экрана (`P13`, `1/16`, `Snap`) живут в UI.

Пока проект один: целиком пишется в `/data/UserData/schwung/ptnmove/project.json` (вне каталога модуля, чтобы deploy не затирал). Сохранение — `onUnload` и debounce ~2 с после изменений; `init` поднимает файл или defaults. Morph и `wanderOriginTick` на диск не живут (сбрасываются); context/page/mode UI восстанавливаются. Состояние транспорта (запущен или остановлен) пишется туда же и поднимается при старте. Файл без этого поля и новый проект стартуют запущенными.

## Коробки

- **Scene** — неизменяемый снимок семи lane. Идентификатор `001`, `002`, … При Record сцена получает псевдослучайный цвет пэда из яркой палитры Move, он хранится на сцене. Journal только дописывается.
- **Working** — живой документ той же формы. Морф пишет в него. Энкодер пишет сразу и снимает это поле с морфа. Record копирует working.
- **Project** — journal, sets (до 32 ссылок на сцены), mixer (7 уровней и master), global, macro offsets, 4 bookmark'а, mute, lock, transition, wander, clipboard (список id сцен для вставки в сет; старый файл с одной строкой читается как список из одного id). В сцену это не входит.

`heard = clamp(stored + macroOffset)` считается в момент генерации фразы. Record offset не запекает. У locked lane offset не применяется. Страницы macro пишут те же offsets: DENS сдвигает probability евклида, REP — repeat и ratchet count, RATE — ratchet rate и rate аккордов. Ключ без ручки, если он уже лежит в файле, по-прежнему применяется.

Mute убирает lane из слышимого выхода. Harmonic events Chords при mute остаются, bass и lead продолжают их читать.

## Lane

Ударные и Bass/Lead: два параллельных евклида `gen1` / `gen2` (`length`, `hits`, `rotate`, `probability`, `velocity` V/P/C/A), без Form и без A/B.

Ударные дополнительно: `ratchet.count/rate`, восемь sound-модуляторов.

Bass и Lead дополнительно: `follow`, генераторы `pitch` и `octave`, `length` (длительность ноты), `repeat`, `step`, восемь sound-модуляторов. Отдельного lane.velocity нет — громкость из `gen*.velocity`. `pitch` 0.5 — тоника выбранной гаммы, края — октава гаммы ниже и выше. `octave` — абсолютная октава тоники, одна шкала у баса и лида: 0 это C0, 9 это верхнее до рояля. По умолчанию бас 2, лид 4. Ступень и октава складываются.

Chords lane: генераторы `tone` / `octave` / `rate` / `gate` / `velocity`, восемь sound-модуляторов, filter и send. Прогрессия — отдельный объект `progression` на сцене и в проекте: `start`, `count`, `length` (доля 0..4: шестнадцатая, восьмая, доля, полтакта, такт), `motion`, `variation`, `mood`, `tension`, `way`. Морф её не смешивает: до приземления слышна прогрессия старта. `tone` 0 — корень текущего аккорда, 1 — верхний тон. `octave` — абсолютная октава 0..9, как у баса и лида, по умолчанию 4. `rate` 0 — блок из всех тонов аккорда внутри выбранной октавы, так что ходьба корня не уводит фактуру; генератор `tone` не выбирает голос; (0, 1] — один тон, выбранный `tone`, арпеджио от 1/1 до 1/64, длина ноты `gate` на шаг. `velocity` задаёт громкость каждой ноты, по умолчанию 0.85, макрос `velocity` её сдвигает. `rate`, `gate`, `tone`, `octave` и `velocity` читаются на каждой ноте арпеджио; блок проверяется раз в шестнадцатую и держит весь стек в октаве, прочитанной в его начале. Макрос `length` на аккорды не действует. Сохранённый аккордовый лейн без `tone` и `octave` не читается и заменяется заводским.

Метр — `global.bar`. `follow` только у bass/lead.

Евклид:

```text
phraseSteps = max(length1, length2)   // length 0 = off
local = step mod length
pattern = rotate(euclid(hits, length))
if hash(seed, lane, gen, step) >= probability → skip hit
```

`probability` 1 оставляет все удары кольца, 0 глушит генератор. Короткое кольцо повторяется внутри более длинной петли. На одном шаге оба попали → одно событие, velocity = max.

Модулятор (полный V/P/C/A), в том числе у gen.velocity:

```text
cycle = max(1, round(cycle))
phase = (step mod cycle) / cycle
out = clamp(value + motif(pattern, phase) * amount)
```

`step` — позиция в шестнадцатых. Генератор идёт сам по себе и не считает note on. Нота, ratchet и повтор читают значение в свой момент. Звуковые параметры вроде фильтра голос читает заново на каждом сэмпле, пока нота звучит. `amount = 0` оставляет центр. Сцена хранит id мотива. Форма — `motif(id, phase)` версии `MOTIF_BANK_VERSION` (сейчас 1), 64 формы.

## Clock

192 PPQN. Темп и swing в Global. Swing 0 прямой; swing 1 задерживает нечётные шестнадцатые на половину шестнадцатой уже после сетки генератора. Фраза каждого lane играется по кругу на своей длине. Ход ведёт `dsp.so` по аудиоблокам, поэтому темп не зависит от того, как часто интерфейс успевает перерисоваться.

Хеш вероятности: `seed + lane + generator + "prob" + step`. Идентификатора сцены в хеше нет.

Ratchet и Repeat считают исходное событие за единицу: count 1 — одно событие. Повторы Repeat сдвигаются на `step` ступеней лада.

## Гармония

`HarmonicEvent` — `startTick`, `lengthTicks`, `root` (ступень), `quality` (0..7: maj, min, sus2, sus4, 7, m7, dim, aug). Длины сидят на сетке долей такта и в сумме равны фразе. `variation` выше нуля укорачивает часть аккордов до проходящих, время забирает сосед. Качество одно на фразу, из `mood` и `tension`. Bass и Lead берут желаемую ступень выбранной гаммы: `follow` 0 оставляет ноту гаммы, `follow` 1 сажает на ближайший тон звучащего аккорда. Порядок голосов аккорда на их ноты не влияет. `global.root` — нота тоники, `global.scale` — лад (minor, major, dorian, mixolydian).

Генерация фразы и preview — одна функция `generatePhrase`.
